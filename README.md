# miniplanes

Założenia projektu:

Projekt to gra strategiczna, której głównym celem jest tworzenie linii połączeń lotniczych, po których przewożeni są pasażerowie.
Trudnością jest dobranie sposobu projektowania sieci linii tak, aby nie generować zakorkowań pasażerów w żadnym z miast.
